# liberty-es

Modificación del [estilo `liberty` de *OpenFreeMap*](https://github.com/hyperknot/openfreemap-styles/tree/main/styles/liberty), el cual es un fork del [estilo `liberty` de *Maputnik*](https://github.com/maputnik/osm-liberty).

Ambos proyectos me parecen grandiosos y estoy aprendiendo mucho de ellos, por lo que les estoy sumamente agradecido.

## Metodología

Descargado el estilo crudo [https://tiles.openfreemap.org/styles/liberty](https://tiles.openfreemap.org/styles/liberty), reemplacé todas las instancias `name_en` por `name:es`.
